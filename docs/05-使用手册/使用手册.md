# 使用手册

状态：初始化；尚无可用的新平台页面，本文件不构成当前产品操作指南。

## 适用读者

通过中文网页管理项目、研发任务、人工确认和交付结果的用户。

## 计划中的主路径

接入项目 → 使用标准团队 → 选择 SOP → 确认执行安排 → 启动 → 查看进度与处理人工事项 → 审查交付。

以上来自[原始需求](../project-reform/原始需求文档.md)，尚未实现。产品日常管理仅提供 WebUI，不要求用户学习 OpenRig CLI、TUI 或网页终端。

## 实现后补充

按实际页面逐项记录前置条件、操作步骤、结果、错误恢复及中文外部授权引导。登录或操作系统确认不能由平台默默代为授权。完成、验证通过和用户验收分别说明。
