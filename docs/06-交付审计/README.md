# 交付审计归档

本目录按 dev-project-init 建立，用于归档后续 dev-delivery-check 的真实报告，当前没有产品交付通过结论。

文件名采用 `delivery-check-YYYY-MM-DD[-suffix].md`。每份报告记录检查范围、代码版本、需求/规格/计划/代码对应、测试证据、问题和结论；未运行项不得计入通过。

需求入口为 `../01-需求文档/需求.md`，沿引用读取唯一原始需求；现有阶段 0/A 规格位于 `../03-技术架构/阶段0A执行基础规格.md`，后续规格和计划位于 `../superpowers/`。审计以具体任务引用的权威文件为准。

初始化不运行发布、push 或 tag 操作；后续实际操作遵循用户授权，不因模板提及 tag 就自动执行。
