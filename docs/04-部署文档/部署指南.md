# 部署指南

状态：初始化；新平台尚不可部署。本文没有经过验证的安装、启动、健康检查或回滚命令。

## 计划部署形态

中央为前端静态服务、FastAPI 和 MySQL；执行节点为 Python daemon 与 Codex，Mac 使用 launchd，Linux 使用 systemd。具体配置在相应阶段验证后记录。

## 环境与凭证

Python 使用 uv 管理的独立环境，不修改全局解释器。凭证只存受保护且忽略提交的本机配置或安全存储，不写入镜像、Git、任务日志和文档。
